# ربات استخراج و تحلیل کانال تلگرام

این پروژه برای استخراج تاریخچه یک **کانال عمومی** با حساب کاربری مجاز تلگرام ساخته شده است. ربات تلگرامی فقط رابط فرمان است؛ خواندن تاریخچه با کتابخانه Telethon و نشست حساب کاربری انجام می‌شود.

## امکانات نسخه اول
- استخراج پست‌های آخر یا کل تاریخچه
- ذخیره متن، تاریخ UTC، شناسه پست، بازدید، فوروارد، پاسخ‌ها، واکنش‌ها و نوع/حجم رسانه
- ساخت فایل‌های JSON و CSV و یک ZIP شامل هر دو
- کنترل ربات فقط توسط شناسه عددی مدیر

**محدودیت:** فایل عکس/ویدئو را دانلود نمی‌کند؛ فقط نوع و اندازه رسانه را ثبت می‌کند. کانال باید عمومی باشد و حسابی که نشست آن را می‌سازید باید اجازه مشاهده کانال را داشته باشد. این پروژه برای دور زدن محدودیت دسترسی یا استخراج محتوای خصوصی طراحی نشده است.

## راه‌اندازی از آیفون با یک محیط ابری
برای اجرای ۲۴ساعته به یک محیط میزبانی ابری نیاز دارید. می‌توانید از محیطی مثل Replit استفاده کنید؛ رابط و مراحل ممکن است با تغییرات سرویس عوض شود.

1. فایل ZIP پروژه را در یک پروژه Python جدید در محیط ابری بارگذاری/استخراج کنید.
2. در Shell ترمینال، وابستگی‌ها را نصب کنید:
   `pip install -r requirements.txt`
3. از `my.telegram.org` وارد حساب خود شوید و در API development tools یک `API_ID` و `API_HASH` بسازید.
4. در تلگرام با BotFather یک ربات بسازید و `BOT_TOKEN` بگیرید.
5. شناسه عددی حساب تلگرامی خود را به‌عنوان `ADMIN_ID` مشخص کنید (از یک ربات معتبر نمایش‌دهنده User ID می‌توانید کمک بگیرید).
6. در بخش Secrets / Environment Variables هاست این متغیرها را اضافه کنید:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`
   - `ADMIN_ID`
7. در Shell، یک بار دستور زیر را اجرا کنید:
   `python auth.py`
8. شماره تلفن را با کد کشور وارد کنید؛ کد ورود تلگرام را فقط در همان ترمینال امن وارد کنید. اگر تأیید دومرحله‌ای فعال است، رمز آن را نیز همان‌جا وارد کنید.
9. برنامه یک `SESSION_STRING` چاپ می‌کند. آن را در Secrets هاست با همین نام `SESSION_STRING` ذخیره کنید. این رشته مثل کلید ورود به حساب شماست؛ آن را در چت، گروه یا برای هیچ‌کس ارسال نکنید.
10. برنامه را با دستور `python main.py` اجرا کنید.

## فرمان‌ها در ربات
- `/start`
- `/help`
- `/status`
- `/export sc6rn 200` برای ۲۰۰ پست آخر
- `/export sc6rn 0` برای کل تاریخچه

برای کانال دیگر، به‌جای `sc6rn` نام کاربری عمومی آن را وارد کنید.

## امنیت
- `SESSION_STRING` و `API_HASH` و `BOT_TOKEN` محرمانه‌اند.
- پروژه را در مخزن عمومی منتشر نکنید.
- فقط خودتان را به‌عنوان `ADMIN_ID` تنظیم کنید.
- اگر نشست لو رفت، از تنظیمات تلگرام > Devices نشست‌های ناشناس را خاتمه دهید.
- استخراج انبوه ممکن است با محدودیت نرخ تلگرام روبه‌رو شود؛ در این صورت مدتی صبر کنید و دوباره تلاش کنید.
